## 本リポジトリについて
* 本成果物は、基本情報技術者試験・ITパスポート・情報セキュリティマネジメント試験の頻出用語や計算問題を効率的に暗記・演習するために開発した単語帳 Web アプリケーションです

* 大量の知識データを体系的に集約し、学習効率を高める独自のロジックと UI を設計・実装しました

### 開発の経緯
* 2025年12月より完全独学で資格対策を開始した際、費用をかけずに学習効率を最大化することを目標としました。アプリの開発期間は【2025/12〜2026/04】です

* 動画学習や過去問演習（過去問道場）を進める中で、重要単語や頻出パターンを自身でまとめたメモが約25,000KB（Excel）規模まで膨大化。既存のテキストデータだけでは反復学習がしづらいと感じたため、「自分にとって最も効率的な単語帳ツールを自分で作ろう」と一気に立ち上がり、HTML/CSS/JavaScriptを用いてWebアプリとして構築・可視化しました

* 2026/04/01台湾から日本への渡航直後、2日間で3試験を受験するというハードなスケジュールの中で本ツールを徹底活用し、効率的な直前復習を実現。結果としてITパスポート・基本情報技術者・情報セキュリティマネジメントの3試験すべてに一発合格を達成しました

* 本ツールおよび作成したデータベースは、今後日本でエンジニアとして実務に携わる際にも、IT基礎知識の再確認や辞書的なナレッジベースとして末永く活用・更新していく予定です

### 主な機能・特徴
* 高精度な自作 CSV パーサー： カンマ/セミコロンの自動判定、セル内改行、引用符（"）のエスケープ処理に完全対応した堅牢な解析ロジックを搭載
* 柔軟な出題カスタマイズ： 「テクノロジ系」「ストラテジ系」「マネジメント系」等の分野別フィルタリング、および「ランダム」「順番通り」の出題モード切替に対応
* 複数データソースの読み込み： サーバー上のデフォルト CSV の自動取得（fetch API）、プリセットファイルのワンタップ切替、およびユーザー独自のローカル CSV ファイル読み込み（File API）に対応
* 段階的フェードイン演出： 答え表示時、setTimeout 制御により文字色を段階的に濃く変化させ、記憶の定着を促す視覚的工夫を実装
* 動的エラーハンドリング： 選択ファイルが存在しない場合や分野不一致時に、適切なアラートメッセージを表示してユーザーの誤操作を防止

### 今後の課題・発展性
* 学習メモ作成時、スプレッドシート上に図解や問題画像を埋め込んで作成しましたが、CSV 形式へ変換・ダウンロードする際に画像データが欠損・脱落してしまう技術的課題が残っています。今後は画像ファイルのローカル保存・パス参照への切り替えや、JSON 化による画像バイナリ/URL の保持構造へのリファクタリングを行い、図解問題にも完全対応できるよう改善を図る予定です

* 画像データの保持など技術的な課題の解決を進めるとともに、今後日本での就職後も、業務で必要な技術・知識を随時アップデートして自身の実務用ナレッジベースとして継続活用していく予定です

## 使い方
### VS Code の Live Server を使う（推奨）
> ※ Web API (fetch) の仕様上、直接 `.html` をダブルクリックせずローカルサーバー経由で開く必要があります。

1. VS Code で本プロジェクトのフォルダーを開く
2. 拡張機能 `Live Server`（Ritwick Dey 著）をインストール
3. `対策.html` を右クリックし、**`Open with Live Server`** を選択（または右下の `Go Live` をクリック）
4. 自動的にブラウザが立ち上がり、アプリが利用可能になる

### ExcelからCSVを作り直す方法
* 前提：Windows、デスクトップ版Microsoft Excel、PowerShell。`ファイル\基本情報技術者対策.xlsx` の**左から5つのシート**がCSV出力の対象です。実行すると、各シート名のCSVを `ファイル` フォルダーに保存し、同名の既存CSVを上書きします。必要に応じて事前にバックアップしてください

```powershell
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force
```

* 上記は現在のPowerShellプロセス内だけ実行ポリシーを緩和し、スクリプトをUTF-8として読み込んで実行します。PowerShell 5.1ではUTF-8 BOMなしのスクリプトを直接実行すると、日本語を含む行が文字化けして構文エラーになる場合があります

## 注意事項
* クイズページはCSVを取得するため、`対策.html` を直接開くのではなく、ローカルWebサーバー経由で開いてください。詳しくは[こちら](#vs-code-の-live-server-を使う推奨)
* ExcelからCSVを生成するPowerShellスクリプトは、ExcelをCOM経由で操作します。Microsoft Excelがインストールされていない環境では実行できません
* スクリプト実行後にExcelプロセスが残るなどの問題が起きた場合は、Excelを閉じてから再実行してください
